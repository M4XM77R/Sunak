Profile

Providers

Ollama runs models on your computer. Add Claude with an Anthropic API key, or any OpenAI-compatible API (OpenAI, OpenRouter, Groq, LM Studio, llama.cpp, vLLM). Keys are stored only on this computer and never sent back to the browser.

Chat

After an answer the chat’s model notes lasting facts, e.g. your name or how you like answers. Passwords and keys are never kept. You see them under Notes & Memory, where you can edit or delete them. “Remember that …” in a chat is always kept.

Voice

The microphone next to the message box turns speech into text, the speaker under an answer reads it aloud.

Personas

Pick a persona above the chat to change how Sunak answers, e.g. as a coder or translator. Edit them or add your own.

Mail accounts

Link as many e-mail accounts as you like (Gmail, Outlook, iCloud, GMX, WEB.DE, your own server…). Most providers need an app password instead of your normal password. Passwords stay on this computer and are never sent back to the browser. Sunak reads your mail without marking it as read and sends only when you click Send.

Calendars

Sunak has its own calendar. Add your calendars from iCloud, GMX, WEB.DE, Nextcloud, mailbox.org and others (CalDAV), often with the login of a linked mail account, or subscribe to any calendar address (ICS, read-only), e.g. from Google or Outlook. Passwords stay on this computer.

Agent

In agent mode (the terminal button next to the message box) the model works in a project folder you choose: it lists, reads and searches files on its own, and asks you before it writes a file or runs a command. It cannot reach files outside that folder.

Commands run on this computer with your user rights and are not sandboxed: a command can do anything you could do in a terminal. Read each command and change before you allow it, and use agent mode only with folders and models you trust. From other devices it only works with a password.

Tools (MCP)

MCP servers give the model tools, e.g. for your files, web pages or other apps. Switch them on with the plug button next to the message box (they also work in agent mode). Sunak asks you before every tool call. Environment values and tokens stay on this computer and are never sent back to the browser.

A server of type “Program” runs on this computer with your user rights. Add only servers you trust. From other devices tools only work with a password.

Image generation

Make pictures with the picture button next to the message box. Easiest: Sunak’s own image program (stable-diffusion.cpp), which you set up with a click on the Models page. Or connect a Stable Diffusion program running on this computer or in your network: Automatic1111 (also Forge or SD.Next, started with --api) or ComfyUI.

Look

Pick a theme, it applies right away. The accent color below changes buttons and links.

Data

All chats, documents, notes and your knowledge base in one JSON file. API keys and the password are not included.

Phone & tablet

Use Sunak on your phone or tablet in the same Wi-Fi: switch this on, then scan the code with the phone's camera. Needs a password (below), so nobody else in the network can get in. Your computer has to stay on.

Security

Set a password if Sunak is reachable from other devices. Leave empty to disable.
